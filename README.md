# AQUACAR — сайт премиальной автомойки

Статический сайт без сборки: HTML + CSS + ванильный JS. Его можно открыть с любого хостинга
(Netlify, Vercel, GitHub Pages, обычный веб-сервер).

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: машина вид сверху и переход в каталог, преимущества, популярные услуги, отзывы |
| `catalog.html` | Каталог услуг с фото и фильтрами, окна «Подробнее» |
| `reviews.html` | Все отзывы |
| `booking.html` | Форма записи → Telegram (`?service=id` подставляет услугу) |
| `contacts.html` | Адрес, карта, маршрут, мессенджеры |
| `privacy.html` | Политика обработки персональных данных |

Шапка, футер, иконки и модальное окно — общие, собираются из `assets/js/layout.js`.
Переходы между страницами — View Transitions (Chrome, Edge, Safari 18.2+), в остальных браузерах — плавная шторка.

## Структура

```
assets/css/        base · layout · hero · sections
assets/js/layout.js            — общий layout + переходы между страницами
assets/js/config.js            — контакты, часы, Telegram
assets/js/data/services.js     — услуги (цены, описания, состав)
assets/js/data/reviews.js      — отзывы
assets/js/services/booking-api.js — отправка заявки / ссылка в Telegram
assets/js/components/*.js      — hero, catalog, modal, compare, reviews, booking-form, header, misc
assets/img/photos/             — фото (Pexels, бесплатная лицензия) + маска вырезки BMW
api/telegram.php, api/config.php — пересылка заявок в Telegram (PHP-хостинг)
api/booking.js                 — то же для Vercel / Netlify Functions
```

## Заявки в Telegram

1. Создайте бота у **@BotFather**, получите токен.
2. Напишите боту `/start` (или добавьте его в группу менеджеров).
3. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и возьмите `chat.id`.
4. Впишите токен и chat_id в `api/config.php` (или задайте переменные окружения
   `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_IDS` — можно несколько id через запятую,
   тогда заявка уйдёт сразу всем менеджерам).
5. В `assets/js/config.js` укажите username менеджера в `telegramManager`.

Как это работает:
- форма отправляет заявку на `api/telegram.php`, бот присылает её менеджерам;
- если сервер не настроен или недоступен, клиенту показывается кнопка
  «Отправить заявку в Telegram»: открывается чат с менеджером, текст заявки уже вставлен;
- если в `config.js` оставить `endpoint: ''`, форма всегда сразу открывает чат с менеджером.

Токен хранится только на сервере, в браузер он не попадает. Есть защита от ботов
(скрытое поле), лимит заявок с одного IP и проверка домена.

## Персональные данные (152-ФЗ)

Что уже сделано на сайте:
- отдельные документы: [privacy.html](privacy.html) (политика) и [consent.html](consent.html) (согласие); без галочки согласия форма не отправляется;
- заявка сначала записывается на сервер (`api/storage/bookings-ГГГГ-ММ.jsonl`, закрыто от браузера) и только потом уходит в Telegram — требование о локализации;
- вместе с заявкой сохраняется подтверждение согласия: время, IP, браузер, версия документа;
- шрифты размещены на сайте, сторонних счётчиков и рекламных cookie нет — данные посетителей не уходят в Google и другие сервисы.

Что нужно сделать вам (кодом это не решается):
1. Заполнить подсвеченные жёлтым поля в `privacy.html` и `consent.html` (наименование, ИНН, ОГРН, адрес, хостинг, ответственный) и удалить жёлтую плашку-напоминание.
2. Подать в Роскомнадзор уведомление об обработке персональных данных и отдельное уведомление о трансграничной передаче (Telegram) — на pd.rkn.gov.ru; номер из реестра вписать в политику.
3. Разместить сайт на хостинге с серверами в РФ и использовать `api/telegram.php` (вариант для Vercel хранит данные за рубежом).
4. Раз в месяц удалять файлы заявок старше срока хранения (1 год), назначить ответственного за обработку ПДн.

Документы составлены по структуре 152-ФЗ, но это шаблон: перед запуском их стоит один раз показать юристу.

## Что заменить перед запуском

1. **Домен** `https://aquacar.ru/` во всех `*.html` (canonical, og:url, og:image, JSON-LD), `robots.txt`, `sitemap.xml`.
2. **Контакты**: телефон, адрес, e-mail, ссылки на Telegram / WhatsApp / VK — в `index.html` (поиск по `120-45-67`, `aquacar_moscow`), в `assets/js/layout.js` (шапка и футер) и `assets/js/config.js`.
3. **Telegram**: токен и chat_id в `api/config.php`, username менеджера в `assets/js/config.js`.
4. **Координаты** для кнопки «Построить маршрут» — в ссылках `yandex.ru/maps` в блоке контактов.
5. **Цены и услуги** — `assets/js/data/services.js` (карточки, фильтры, модальные окна и список в форме обновятся сами).
6. **Отзывы** — `assets/js/data/reviews.js`.
7. **Цифры** в блоке преимуществ и в hero (`4,9`, `12 лет`, `25 000+`).

## Главный экран

Машина нарисована в SVG (вид сверху) прямо в `index.html`, вокруг — моечный бокс из CSS.
По «Перейти в каталог» камера приближается, машина чуть приседает и уезжает вперёд,
через ~0,7 с открывается каталог (`assets/js/components/hero.js`). При «уменьшении движения» — сразу переход.

## Кэш

К CSS и JS в `index.html` добавлен параметр `?v=2.3.1`. После правок увеличьте версию,
чтобы посетители сразу получили обновление.
